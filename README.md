# My skills

This is my personal collection of skills that I've created and use daily. Skills give AI agents instructions for specific tasks, such as making text easier to read.

## Install

With Node.js and npm installed, run this command in your terminal:

```sh
npx skills add chand1012/skills
```

Follow the prompts to choose the skills to install and the agents that will use them.

To install just a single skill, run:

```sh
npx skills add chand1012/skills --skill <skill name>
```

See the [Skills CLI documentation](https://github.com/vercel-labs/skills) for more installation options.

## Available skills

- [Easyread](skills/easyread/SKILL.md): Write, revise, or review explanations so people can understand them on a first reading.
- [Meme](skills/meme/SKILL.md): Create comics, captioned images, and reaction memes from ideas or image templates.
- [Satori](skills/satori/SKILL.md): Design polished graphics in HTML/CSS and render SVG or PNG files with a TypeScript CLI.
- [Summary](skills/summary/SKILL.md): Summarize material or topics at three levels of detail, preserving the reasoning and qualifications needed to discuss them accurately.
